# EDA on Retail Sales Analysis

### 📊 Objective
Thorough EDA on retail sales to uncover patterns, customer behaviour & business insights

### ✅ Checklist Completed
- [x] Load dataset: shape, dtypes, null check
- [x] Descriptive stats: mean, median, mode, std
- [x] Time series: monthly & quarterly sales trends
- [x] Customer demographics: age groups, gender
- [x] Product analysis: Top 10 best sellers, revenue by category
- [x] Heatmap: correlation matrix
- [x] Extra viz: non-obvious insight
- [x] Markdown observations + 3 business recommendations

### 📈 Key Insights & Business Recommendations
1. Focus marketing on top 3 categories which give 70% revenue
2. Weekend sales high - increase staff & offers on Sat-Sun
3. Age group 25-35 highest buyers - target ads to them

### Tech: Python, Pandas, Matplotlib, Seaborn, Jupyter
